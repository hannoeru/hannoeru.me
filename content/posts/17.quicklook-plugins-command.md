## 安裝

### 使用 [Homebrew Cask][1]

> **注意：** `brew cask install` 已在 Homebrew 3.0（2021 年 2 月）移除。現在的語法是 `brew install --cask`。本文的指令已全部更新。

安裝插件：

```bash
brew install --cask <package>
```

安裝全部插件：

```bash
brew install --cask qlcolorcode qlstephen qlmarkdown quicklook-json qlimagesize webpquicklook suspicious-package quicklookase qlvideo
```

## 指令

顯示幫助

```bash
qlmanage -h
```

指定 QuickLook 開啟檔案

```bash
qlmanage -p filename.jpg
```

清除 QuickLook 快取

```bash
qlmanage -r cache
```

重新載入插件

```bash
qlmanage -r
```

Quick Look 的故障排除，通常清除快取並重新載入插件就可以解決問題。

如果無法排除，使用命令方式開啟檔案，就會看到詳細錯誤信息。

在安裝新插件後要重新載入插件才會生效。

## 插件

### [QLColorCode][2]

在預覽時幫程式碼加上顏色，幫助閱讀。

```bash
brew install --cask qlcolorcode
```

### [QLStephen][3]

預覽沒有或具有未知副檔名的文件，以純文本顯示。例如：README，CHANGELOG，index.style 等...

```bash
brew install --cask qlstephen
```

### [QLMarkdown][4]

預覽 Markdown 文件

```bash
brew install --cask qlmarkdown
```

### [QuickLookJSON][5]

預覽 JSON 文件

```bash
brew install --cask quicklook-json
```

### [BetterZipQL][6]

預覽壓縮檔

注意：BetterZipQL 包含在 BetterZip APP 內，安裝時會一併安裝 BetterZip。

```bash
brew install --cask betterzip
```

### [qlImageSize][7]

顯示照片大小與解析度

> 較新版本的 macOS 已内建顯示常見格式的尺寸資訊，這個插件主要對 HEIC 等格式仍有幫助。

```bash
brew install --cask qlimagesize
```

### [WebP][8]

預覽 WebP 圖像

```bash
brew install --cask webpquicklook
```

### [Suspicious Package][9]

預覽標準 Apple 安裝程式內容

```bash
brew install --cask suspicious-package
```

### [QuickLookASE][10]

預覽 Adobe ASE 色表

```bash
brew install --cask quicklookase
```

### [QLVideo][11]

預覽大多數的影像檔，會自動生成縮圖、封面跟詳細數據。

> 在 macOS 12 以上版本有已知的相容性問題，安裝前請先確認[支援狀況][11]。

```bash
brew install --cask qlvideo
```
