## Apps

> **Note:** This list was refreshed in August 2026 to match my current setup. Entries marked with ⚡ replaced an app from the old 2021 list.

### Browsers

- [Arc](https://arc.net/) My daily browser.
- [Google Chrome](https://www.google.com/chrome/) (+ Canary) For web dev and cross-browser testing.
- [Firefox Developer Edition](https://www.mozilla.org/firefox/developer/) Secondary browser for development.

### Dev

- [VS Code](https://code.visualstudio.com/) (+ Insiders) Code editor.
- [Cursor](https://cursor.com/) AI code editor.
- [Xcode](https://developer.apple.com/xcode/) For iOS/macOS development.
- [Android Studio](https://developer.android.com/studio) For Android development.
- [Ghostty](https://ghostty.org/) ⚡ Terminal (replaced iTerm2).
- [Neovim](https://neovim.io/) Terminal editor, used over SSH on remote machines.
- [OrbStack](https://orbstack.dev/) ⚡ Fast, light Docker & Linux VMs (replaced Docker Desktop — see [my Multipass post](/posts/replace-docker-desktop-with-multipass) for the older approach).
- [Lens](https://k8slens.dev/) Kubernetes IDE.
- [MQTTX](https://mqttx.app/) MQTT client, great for IoT/Home Assistant debugging.
- [Wireshark](https://www.wireshark.org/) Network protocol analyzer.
- [Dataflare](https://dataflare.app/) Database GUI client.

### AI

- [ChatGPT](https://chatgpt.com/) Desktop app.
- [Claude](https://claude.ai/) Desktop app.
- [Wispr Flow](https://wisprflow.ai/) Dictation with AI.
- [superwhisper](https://superwhisper.com/) Offline speech-to-text for writing.

### Design & Creative

- [Figma](https://www.figma.com/) UI design tool.
- [Adobe Creative Cloud](https://www.adobe.com/creativecloud.html) After Effects, Lightroom, Media Encoder.
- [Photomator](https://www.pixelmator.com/photomator/) Photo editing.
- [Final Cut Pro](https://www.apple.com/final-cut-pro/) Video editing.
- [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve) Color grading and video editing.

### Tools

- [Raycast](https://www.raycast.com/) ⚡ Launcher, clipboard history, snippets (replaced Alfred).
- [AltTab](https://alt-tab-macos.netlify.app/) Windows-style window switching.
- [BetterTouchTool](https://folivora.ai/) Customize various input devices.
- [Karabiner-Elements](https://karabiner-elements.pqrs.org/) Powerful keyboard customizer.
- [Stats](https://github.com/exelban/stats) Menu-bar system monitor.
- [MonitorControl](https://github.com/MonitorControl/MonitorControl) External display brightness and volume.
- [Mos](https://mos.caldis.me/) Smooth scrolling for third-party mice.
- [Input Source Pro](https://inputsource.pro/) Auto-switch input method per app.
- [SwitchResX](https://www.madrau.com/) Custom display resolutions.
- [Keka](https://www.keka.io/) File archiver.
- [AppCleaner](https://freemacsoft.net/appcleaner/) Thoroughly uninstall unwanted apps.
- [CleanMyMac](https://cleanmymac.com/) System cleanup.
- [iMazing](https://imazing.com/) iPhone/iPad backup and transfer.
- [Syncthing](https://syncthing.net/) Continuous file sync between devices.
- [balenaEtcher](https://etcher.balena.io/) Flash OS images to SD cards/USB.
- [Google Drive](https://www.google.com/drive/) / [MEGA](https://mega.io/) Cloud storage.

### QuickLook Plugins

- QLMarkdown, QLStephen, QLVideo, QuickLook CSV/Video, Syntax Highlight, PictureView — see [my QuickLook plugins post](/posts/quicklook-plugins-command).

### Communication & Email

- [Slack](https://slack.com/) / [Discord](https://discord.com/) Team and community chat.
- [LINE](https://line.me/) / [Telegram](https://telegram.org/) Messaging.
- [Canary Mail](https://canarymail.io/) ⚡ Email client (replaced Spark).
- [Thunderbird](https://www.thunderbird.net/) Backup email client.

### Remote & VM

- [Parallels Desktop](https://www.parallels.com/) Windows VM.
- [Moonlight](https://moonlight-stream.org/) Game streaming client.

### VPN & Network

- [Tailscale](https://tailscale.com/) ⚡ Zero-config mesh VPN (replaced manual WireGuard/OpenVPN setups).
- [WireGuard](https://www.wireguard.com/) Fast modern VPN.
- [OpenVPN Connect](https://openvpn.net/client/) OpenVPN client.
- [Cloudflare WARP](https://1.1.1.1/) Secure DNS/proxy.
- [WiFiman](https://www.ui.com/wifiman/) UniFi network scanning.

### PDF

- [PDF Expert](https://pdfexpert.com/) Fast, robust PDF editor.

### 3D & Printing

- [Blender](https://www.blender.org/) 3D creation suite.
- [FreeCAD](https://www.freecad.org/) Parametric 3D CAD.
- [Shapr3D](https://www.shapr3d.com/) iPad-first CAD on the Mac.
- [UltiMaker Cura](https://ultimaker.com/software/ultimaker-cura) 3D printing slicer.
- [OrcaSlicer](https://orcaslicer.com/) / [Bambu Studio](https://bambulab.com/download/studio) Modern slicers.

### Music

- [VOX](https://vox.rocks/) Music player.
- [Logic Pro](https://www.apple.com/logic-pro/) DAW.
- [Serato DJ Pro](https://serato.com/dj/pro) / [rekordbox](https://rekordbox.com/) DJ software.
- [BlackHole](https://existential.audio/blackhole/) Virtual audio driver for routing audio between apps.

### Media

- [IINA](https://iina.io/) / [VLC](https://www.videolan.org/) Media players.
- [OBS](https://obsproject.com/) Streaming and recording.
- [Spotify](https://www.spotify.com/) Music streaming.
