### 技巧

#### GMT、UTC 與 TimeStamp

- **GMT（格林威治標準時間）**：以英國格林威治天文台為基準的舊時間標準。
- **UTC（世界協調時間）**：目前國際通用的時間標準，與 GMT 幾乎相同（誤差在 1 秒内），現代系統一律使用 UTC。
- **Timestamp（時間戳）**：從 1970-01-01 00:00:00 UTC 開始累計的毫秒數（JavaScript）或秒數（其他語言），與時區無關。可以用 `Date.now()` 取得，也可以用 `new Date(timestamp)` 轉回時間物件。

要在 JavaScript 處理各國時區，最簡單的方式是 `toLocaleString()` 加上 `timeZone` option。

#### **`toLocaleString()`** 函式用法

```js
const time = new Date()

// 第一個參數：顯示語言＆格式
// 第二個參數：option
console.log(time.toLocaleString('en-GB', {
  timeZone: 'UTC',
  hour12: false,
}))
```

這次使用到的 Option 有兩個：

- timeZone
  - 可以接受像是 "America/New_York" 這樣的時區，參閱：[IANA time zone database][1]
- hour12
  - true //12小時制
  - false //24小時制
